# Quiz e página de vendas — Biblioteca do Professor

Site estático, separado do aplicativo. O quiz fica em `index.html`; ao concluir, o botão leva para `vendas/index.html`.

## Visualizar localmente

Abra `index.html` no navegador. Para simular o site publicado, use um servidor estático local para que os links relativos funcionem.

## Publicar

Este projeto não precisa de etapa de build. Conecte a raiz do repositório ao provedor de hospedagem estática. Confirme que o quiz e a página de vendas usam o mesmo domínio/pasta-base para manter os links relativos.

Antes de publicar, substitua os espaços reservados de prova social por mensagens reais autorizadas e complete preço, checkout, condições de acesso e identificação legal do responsável.
